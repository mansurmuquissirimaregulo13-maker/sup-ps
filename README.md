# Takealot PS5 Checkout Demo

Este repositório contém duas páginas HTML de checkout:

- `order.html` – checkout para o JBL Charge 6.
- `playstation_5_gta6.html` – checkout para a PlayStation 5 + GTA 6 bundle.

Ambas as páginas foram desenvolvidas como exemplo de checkout seguro com integração de Facebook Pixel, UTMify, e pagamento via CreaPay/Paystack.

## Como testar

1. Abra o arquivo HTML localmente no navegador.
2. Modifique os parâmetros da URL (`?p=...&color=...&qty=2`) para trocar o produto ou a quantidade.
3. Preencha o formulário de endereço e clique em **PROCEED TO SECURE PAYMENT** para ver o fluxo de pagamento.
